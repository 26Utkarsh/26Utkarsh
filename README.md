## Flagship · InsightFlow

An AI-powered BI and analytics platform that turns uploaded datasets into interactive, AI-assisted insights.

- Import and profile structured data; explore KPIs and interactive charts.
- Generate contextual insights and trends with Gemini.
- Work with CSV and spreadsheet files in a responsive dashboard.

**Built with:** React · TypeScript · Vite · Tailwind · Recharts · Gemini API · PapaParse · SheetJS
