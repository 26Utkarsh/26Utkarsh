## 🌟 Featured Projects Showcase

### 🔥 **InkWire** — AI-Powered News Publishing Platform
> **[Repository](https://github.com/26Utkarsh/InkWire)** | **Production Ready** ✅

A **fully automated, enterprise-grade news publishing platform** powered by Google Gemini 2.5 Flash AI. Aggregates 7+ global news sources, auto-generates SEO-optimized articles, manages editorial workflows, and publishes on a daily schedule.

**🎯 Key Highlights:**
- ✅ **Dual AI Engine:** Google Gemini 2.5 Flash (primary) + Groq LLaMA 70B (fallback)
- 🎨 **BBC-Inspired Article Layout** with Playfair Display typography
- 📰 **Smart News Crawler:** Aggregates RSS feeds from BBC, Reuters, The Hindu, NDTV, TechCrunch, Al Jazeera
- 🔖 **Bookmark System:** localStorage-persistent reading list with offline access
- 📧 **Newsletter Dispatch:** Automated email distribution to subscribers
- 🛡️ **Enterprise Security:** HttpOnly JWT cookies, CSRF protection, rate limiting, hardened CSP
- 📊 **Editorial Dashboard:** Real-time control room with queue management and publishing scheduler
- 🚀 **2025 Performance Optimizations:** Code-splitting, Brotli compression, GPU animations
- 🔗 **Live Demo:** Deployed on Render (Backend) + Netlify (Frontend)

**Tech Stack:** React 18 + Vite 5 | Node.js + Express | MongoDB Atlas | Google Gemini 2.5 | Groq LLaMA | Nodemailer | Leaflet

- 🔗 **NASA API Integration:** Proxied image gallery endpoints
- 📊 **Admin Dashboard:** Create, update, and manage missions

**Tech Stack:** React 18 | Vite | Tailwind CSS v4 | Framer Motion | Node.js + Express | MongoDB
