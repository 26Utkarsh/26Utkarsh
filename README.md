It turns uploaded data into an explorable workspace: profile and validate data, inspect key performance indicators, explore interactive charts, and use contextual Gemini-powered analysis to surface trends. Its responsive interface supports CSV and spreadsheet workflows, bringing data preparation, visual exploration, and AI-assisted interpretation together in one product.

<h2 align="center">Featured · InkWire</h2>

**[Repository](https://github.com/26Utkarsh/InkWire)** · [Live demo](https://inkwire.netlify.app) · **Production**

InkWire is a fully automated, enterprise-grade AI news publishing platform powered by Google Gemini 2.5 Flash. It brings together real-time coverage from global news sources, AI-assisted editorial workflows, and a polished reading experience. The system demonstrates end-to-end product work—from content aggregation and resilient AI services to secure publishing operations and deployment.

- **Dual AI insights** for contextual news analysis.

- **Vision 2047 simulator:** budget allocation and economic projection tool.
